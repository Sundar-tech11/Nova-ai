# 📖 Overview

NextStep AI is an AI-powered career companion that provides personalized career guidance, resume analysis, interview preparation, roadmap generation, portfolio building, and skill tracking.

Instead of using multiple platforms, users can access all career development tools in one modern dashboard.

# 🚀 Installation

```bash
git clone https://github.com/Sundar-tech11/Nova-ai.git

cd Nova-ai

npm install
```

Create `.env`

```env
NODE_ENV=development

PORT=3000

GEMINI_API_KEY=YOUR_API_KEY
```

Run

```bash
npm run dev
```

Build

```bash
npm run build
```

Production

```bash
npm start
```
